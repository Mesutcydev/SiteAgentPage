How it works

From idea to verified deploy.

SiteAgent keeps the agent loop visible: your repository, proposed edits, preview, approval, and deployment status stay in one workspace.

01

Connect a repo

Sign in with GitHub or use a token, then choose the repository, branch, technology, and hosting setup.

02

Choose an assistant

Use a connected cloud provider, OpenCode Go, or a compatible on-device model. Credentials stay in Keychain.

03

Describe the change

Ask in plain language. The agent can inspect files and use tools; write actions become staged changes.

04

Preview and approve

Review the diff and local site preview before approving anything that reaches your branch.

05

Commit and verify

Commit when ready, let the host rebuild, and inspect deployment status or logs from the workspace.

Compatibility

What this build supports.

The downloadable artifact is the iPhone/iPad arm64 sideload build. Website Commander is a separate native macOS app.

AreaCompatible withRequirement
DevicesiPhone and iPadiOS/iPadOS 17.0+
IPA architecturePhysical arm64 iOS devicesSideload / re-sign
RepositoriesPublic or private GitHub repositoriesGitHub access
Cloud AIOpenAI, Anthropic, Gemini, DeepSeek, Grok, Mistral, OpenRouter, OpenCode Go, Qwen Code, Kimi Code, LongCat, GitHub Copilot, and custom OpenAI-compatible endpointsBring your key or sign-in
On-device AIQwen3, Qwen3.5, and Bonsai MLX model families on supported hardwareMemory / storage dependent
DeploymentCloudflare Pages, Cloudflare Workers, Vercel, Netlify, Render, Railway, AWS Amplify, GitHub Pages, and SSH/SFTPToken or hook varies
macOSWebsite Commander, the separate macOS website managerNot this IPA

Cloud models use the account or API key you configure. OpenCode Go requires an OpenCode Go credential; an OpenAI platform key will not authenticate to that service. The sideload IPA is ad-hoc packaged, so your sideload tool may need to re-sign it for your device.
